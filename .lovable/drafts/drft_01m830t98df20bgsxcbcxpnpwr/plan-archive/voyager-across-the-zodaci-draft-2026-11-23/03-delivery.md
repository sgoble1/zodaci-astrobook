## Implementation order

**Batch 1:** shared visual tokens and reusable editorial page patterns; public/member headers, menus, footer and dialog contrast. Validate before spreading changes.

**Batch 2:** public welcome and major public pages; simplify busy openings and retain discovery paths, samples and privacy/calculation proof.

**Batch 3:** member dashboards, tools, long-form reading and personal/shared workspaces; preserve role-specific starting states and specialist device surfaces.

**Batch 4:** product-page surroundings, investor/admin views, coordinated artwork and remaining visual outliers. Record all touched routes and checks in the roadmap.

## Technical approach

- Use existing semantic CSS tokens and shared React controls, with explicit material roles for paper, dark celestial regions, devices and printed products.
- Keep navigation registries, URLs, calculation services, account checks and protected loaders unchanged.
- Apply extruded lettering to selected page openings only; use compact, readable chapter and section headings elsewhere.
- Generate and store new artwork through the existing asset flow; reference images remain references rather than embedded screenshots.
- Audit older material selectors before changing global colors, so light text cannot disappear on newly light backgrounds.

## Acceptance checks

- Representative public, free-member and authorized founder/admin pages render with consistent hierarchy and readable contrast; inaccessible views are explicitly reported.
- No horizontal overflow at 320px, 375px, 393px, tablet and desktop sizes; check enlarged text on representative dense pages.
- Menus, active links, search, reader controls and dialogs remain usable by keyboard, with Escape dismissal and visible focus.
- Images load, headings remain legible, and reduced motion removes nonessential movement.
- Existing relevant tests pass and the automatic preview build is clean. Exercise core signed-in flows with actual authorized state.
- No real payment, email or print order is sent for visual verification.
