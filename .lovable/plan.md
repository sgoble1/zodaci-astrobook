# Zodaci experience plan — Phases 1–4

Built in four batches, one per phase, each verified (tests, desktop and 393px checks) before the next. No page, route or feature is removed; existing gates and founder privacy stay as they are.

## Phase 1 — Navigation
- Public header: four menus — Products (AstroBooks, AstroComics, Gift Keepsakes), Calculators & Tools (Birth Chart, Ephemeris, Retrograde Guide, BaZi, Relationships), Learn & Academy (Compendium, Philosophy, Source References), Pricing (tiers, book editions, gift claim). Mobile drawer mirrors it.
- Member menu regrouped into Observatory Decks: Broadcast Deck, The Reading Room, The Listening Post, Astral Bureaus. Pages that fit none keep a home under "More stations".
- Cmd+K palette extended to placements, chapters, tools and the founder volumes the account can already open (titles only, never private text).

## Phase 2 — Reading synthesis
- Internal Paradox: detect hard aspects between personal points (squares/oppositions with Sun, Moon, Saturn, Uranus etc.) and write the "inner argument" paragraph from the deterministic library.
- Cross-tradition check: compare today's major transits with the BaZi Day Master balance; shown as "pressure + resource" notes, labelled as a combined reading, not a verified prediction.
- Grounded vignettes added to the placement library (habits, conversation patterns, coping) written as possibilities ("you may…"), never claimed biography.
- Chart result cards in three layers: The Signal, The Blueprint, The Calculation Ledger (UTC degrees, house system, hidden-stem weights).

## Phase 3 — Investors page
- Thesis: calculations, the placement library and ephemeris run in code with no AI cost; AI only for personalization.
- Live inspector: run the 13 Swiss Ephemeris benchmark moments in the browser and show measured differences and actual timing.
- Economics dashboard breakdown: memberships, Lulu books, comics, Shopify merchandise (estimates labelled as estimates).
- Asset register using counts read from the saved founder audit, not typed-in figures.

## Phase 4 — Graphics and consoles
- One medallion style for planet, sign and house markers (brass/oxblood, orbit rings).
- Cast members as faint background operators on chapter dividers, workbench headers and comic endpapers.
- Tactile controls: rotary orb dial, odometer date counter on Ephemeris, paper ledger tabs.

## Open points
- Founder figures (April 420 pages, Zac 198 chapters, Shane 63 chapters): shown only if the saved counts confirm them; otherwise the measured count is shown.
- "Millisecond" timing is displayed as measured, never promised.
