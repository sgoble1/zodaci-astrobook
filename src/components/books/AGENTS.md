# Book presentation
- Product pages keep one live AstroBook reader; PDF download uses the same faces and any adjacent fictional comic stays a separate digest, preventing preview drift and cramped duplicates.
- Founder-specific comic artwork is selected only for authorized matching chart issues, never public samples, preserving private chart boundaries.
- OpenBook fits printed text faces after container resizing and font loading instead of scrolling page excerpts, so dense chart tables remain fully visible across preview touchpoints.
