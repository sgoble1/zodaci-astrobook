# src/lib rules

- astronomy-engine in astro.ts computes charts with selectable houses/source cross-checks; personal pages use profiles with device fallback.
- Relationship math lives in synastry.ts and kua.ts, never in pages.
- Plan names, prices, checkout IDs and price→tier mapping live only in plans.ts (server functions mirror its ID lists); one place to change pricing.
- AstroBook stage order/labels live in bookFulfillment.ts; DB guards and supabase/functions/_shared/book-delivery-rules.ts mirror PAID_STAGES so client and server agree.
- AstroComic scheduling (comicDueFor/nextIssueMonth) and issue scripts live in comic.ts; the admin queue drafts deterministically, without AI spend.
- AstroComic print geometry, art pixel sizes, prompts and preflight live in comicPrint.ts; comicPdf.ts composes proof/print PDFs from the same layout so artwork is always drawn at its printed size.
- Admin tabs are registered in adminTabs.ts (grouped, ?tab= persisted).
- Internal return links use internalDestination to preserve context without off-site redirects.
- AstroBook content is built by buildVolumes() in bookVolumes.ts (six volumes, chart-derived, readings woven in by volumeFor); BOOK_VERSIONS.inside and VersionCompare must describe exactly what it writes.
- Cover artwork variants (per trim shape, with pixel sizes) live in content/coverDesigns.ts; designVariant picks the closest shape so print PPI stays testable.
- shopPresentation owns featured merchandising priority, Atomic Zodiac detection/curated ordering and the next unordered issue calculation; atomic classification uses catalog tags (some titles omit the collection name), and recommendations use owner-scoped confirmed live comic records, never pending checkout rows.
- shopDepartments groups original catalog types; department filters compose with collection and sign filters so browsing never changes atomic classification.
- investorEconomics derives prices from the product registries and labels fallback costs as estimates, never supplier quotes or realized profit.
- currentChapter keeps broadcast reflections deterministic from aspect and natal point; no generated biography or predicted events.
- readingInsights parses only the reading's own text (written placements, houses, length); it never reads the chart or infers anything about the reader.
- memberRoutes lists the pages every account opens as itself; any new member page must be added there (tested) or non-founders get the readings fallback instead.
- keepsakes builds certificate/Star Scroll rows from calculated positions only; the keepsake number is a stable reprint label, never presented as an official record.
- founderAudit compares counts (chapters, words, files) with the saved platform_settings snapshot; it never handles founder text.
- memberCharacter maps saved member_characters to comic stand-ins; unknown ids draw none.
- shopifyCart decides which shop listings collect recipient birth details (explicit 'personalized' tag only) and sends them as underscore cart-line attributes; cart lines are keyed by variant + attributes so two recipients never merge.
- Private-content loaders (protectedContent, privateEditionLoader) retry non-access failures once via lib/retryOnce; access denials never retry, so glitches self-heal without masking real "no access" answers.
- The founder "View as" tier switch (lib/tierPreview) only changes the plan usePlan returns for elevated accounts on that device; server checks always use the real account.
- AstroBook plain-language front matter and "In this chapter" outcomes come from lib/readersCompass, explaining only terms the book actually contains.
- Compass inline segments preserve printed wording and use the existing glossary; previewPdf lays out shared faceProse including separate reflections and blank faces, with measured bounds and browser-independent semantic print colors to prevent export drift.
- dreamSky computes the "Sky that night" (night-of transits to Moon/Neptune/Pluto/South Node, 8th/12th house traffic, motif→factor table) from the ephemeris only; dream_entries and context_flags are owner-only with per-item Readings/Book/Comic scopes (print off by default), reviewed in PrintContextReview before a book is ordered.
- duplicateFinder reports repeated-sentence counts and 6-word fingerprints only and never edits founder text; the shop reads Shopify live through one 15-minute catalog cache (fetchAllProducts).
- keepsakePdf draws keepsakes as vector pdf-lib pages from keepsakes rows; spine.ts is the only spine-width source (Book3D uses it).

- purchaseSync wraps sync-checkout for book/comic return pages; only provider-verified statuses are shown as final.
- lunarCalendar gives Moon quarters from the ephemeris with natal house (timed charts only) and conjunctions; position and timing only, no interpretation.
- AstroBook previews use shared TextFacePayload, semantic chapter topics and Oracle-default Tone throughout planetary/rising/untimed readings and editorial prose; each register keeps measured facts unchanged and planets include an actual closest contact. Angular dignity is assigned only to verified angular houses. The 28 numbered faces run from Table of Contents to Colophon and keep Plate I on verso 6 facing its ruler narrative on recto 7 (a blank after the unnumbered title aligns physical leaves) and prose at 60–135 words; untimed readings remove angle/house geometry and qualify the Moon. previewPdf exports the same faces to prevent reader drift; personal jackets use authorized facts and public samples stay fictional.
- Comic previews use comicNarrative for a deterministic 24-page story and chart-factor ledger; semantic scene/cast slots and panel shapes drive splash, portrait and sequential beats. ComicDigest shares turnable faces, side-reading and PDF across public/member/authorized editions; saved-order scripts stay in comic.ts so preview polish cannot rewrite paid orders.
- The public Classic demo uses only fictional cover-reader charts and local tone/tier state; no profile persistence, AI generation or private edition loaders, so signed-in visitors cannot alter or reveal account data through the simulator.
- BookPreviewOptions carries edition, display name, dedication, tone and composed cover through sample/member/personal leaves. /books reuses its crop-rendered CoverSpec image, including hidden birth details; composed jackets never add lettering in the reader or PDF, preserving custom artwork and print fidelity. Preview material effects are illustrative, not new fulfillment specifications; recipient previews use the authorized selected birth facts, never the buyer’s chart.
- SampleBook maxPages limits numbered interior faces before composition; its PDF reader navigates all resulting sheets, including cover/end matter, so a 25-page request cannot silently truncate the final numbered pages.
- bookPlate composes coordinate-exact chart-relative SVG engravings for all rulers/signs/elements; date-only plates omit lunar positions and contacts. Artwork resolution uses the calculated Sun element on ties and never includes private biographies; PDF rasterizes these same engravings only for print.
- Preview cycle dates use chart-keyed WeakMap caching, avoiding repeated lifetime searches on tone/name edits without retaining an account globally; dated stations reuse skyEvents daily windows.

- Retrograde Guide uses lib/retrogrades daily UTC ephemeris windows for recent/active/upcoming cycles and same-planet double-Rx matches; /retrogood redirects to /retrogrades, which is a member page with section-level paid gates. Shared editions use only authorized birth facts; interpretations never claim observed biography or rank a reader by dignity.
